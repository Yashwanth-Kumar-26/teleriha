Build your first bot

  1. Clone TeleRiHa and enter the module.

    git clone https://github.com/Yashwanth-Kumar-26/teleriha.git
cd teleriha

  2. Build the example CLI or install the command globally.

    cd cmd/riha
go build -o riha .
# or: go install github.com/Yashwanth-Kumar-26/teleriha/cmd/riha@latest

  3. Create a bot token with BotFather and put it in the starter example.

    cd examples/starter
echo "BOT_TOKEN=your_bot_token_here" > .env
go run main.go

  4. Add handlers, middleware, scenes, persistence, and background jobs from the package APIs.

Requires Go 1.24 or newer. The framework communicates with Telegram through Go's standard HTTP stack.
